# Zeen VS Code
[Zeen Programming Language](https://github.com/mealet/zeen) support for Neovim.

## Installation
Make sure you have installed `zeen` and `zeen-lsp` binaries from the latest release. <br/>
Install the extension from VS Code Marketplace.


## Settings
- `zeen.server.path`: path to the `zeen-lsp` binary. Defaults to looking it
  up on `PATH`.

## Build

```sh
npm install
npm run compile
```
